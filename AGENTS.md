# Notes for AI agents

This repository is the public home of Clamshell for Mac, a closed-source paid macOS app. It holds the issue tracker, changelog and documentation. It contains no app source code, so there is nothing to build or test here.

- To use Clamshell from an agent (install, arm, disarm, check state), read [docs/agents.md](docs/agents.md).
- Every `clamshell://` URL command is in [docs/url-commands.md](docs/url-commands.md).
- The canonical product facts (price, requirements, modules) live on https://clamshell.dev. If this repository and the site disagree, the site is right.
- Do not open issues on a user's behalf without their consent, and never include logs, diagnostics or license keys in an issue.
