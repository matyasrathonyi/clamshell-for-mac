# Security

Please report security vulnerabilities in Clamshell for Mac privately by email to [hello@clamshell.dev](mailto:hello@clamshell.dev), with "Security" in the subject line. Do not open a public issue for a security problem.

Include the Clamshell version, your macOS version and what you found. You will get a reply by email. Please give us a reasonable time to ship a fix before you share details publicly.

Security fixes ship as app updates through clamshell.dev, Homebrew and Setapp, and are listed in [CHANGELOG.md](CHANGELOG.md).
